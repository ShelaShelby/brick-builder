BRICK BUILDER
=============

How to run
----------
1. Unzip this folder anywhere (for example on your Desktop).
2. Double-click brick-builder.exe.
3. If Windows shows "Windows protected your PC", click "More info",
   then "Run anyway". (The app is not signed, so Windows asks once.)

Nothing else needs to be installed.

Controls
--------
Place a part ........ pick a part and colour on the left, then left-click
Rotate part ......... R
Remove a brick ...... right-click it (or hover it and press Delete)
Orbit / pan / zoom .. right-drag / middle-drag / mouse wheel
Turn the view ....... Q / E
Select bricks ....... Select tool (S): click, or drag a box
Move selection ...... drag a selected brick, or use the arrow keys
Undo / redo ......... Ctrl+Z / Ctrl+Y
New / open / save ... Ctrl+N / Ctrl+O / Ctrl+S
Instructions ........ Left / Right arrow keys, the slider, or Back / Next
Help ................ F1

Colours in the editor:
  Red    = floating brick (not connected to the baseplate)
  Orange = weak brick (held on by a single stud)

Ready-made builds and their step-by-step instructions are in the "Builds"
screen. "Export PDF" saves the instructions as a printable PDF.
